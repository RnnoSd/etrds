`etrds` stands for **ExtraerTransformarRDS** which is a fetch tool for RDS. Its main goal is to ease querying a RDS database. `etrds` allows a client to write a query using DuckDB lang. It also brings a CLI and an API for python.

This program is not an implementation of a SQL motor, but a wrapper of DuckDB with some features added in top.
